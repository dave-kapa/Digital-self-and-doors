# Insumos - Digital Self: Attention Doors

En esta carpeta se colocarán las transcripciones y documentos en formato `.md` de las conversaciones con ChatGPT y Gemini que sirven como insumos teóricos, conceptuales y metodológicos para el desarrollo del juego virtual "Digital Self: Attention Doors".

- Investigaciones conceptuales y teóricas sobre el factor humano en ciberseguridad.
- Propuestas metodológicas para el desarrollo de la sesión/webinar.
- Framework de desarrollo de habilidades decisionales.
- Ejercicios específicos diseñados.
