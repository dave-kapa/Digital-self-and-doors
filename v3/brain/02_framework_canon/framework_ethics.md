# Principio rector

El framework debe desarrollar agencia sin culpabilizar, humillar ni exponer a las personas. La emoción puede utilizarse para hacer visible un mecanismo, pero la experiencia debe devolver control, dignidad y posibilidad de aprendizaje.

## Principios canónicos

1. Humanizar, no culpabilizar.
2. Activar emoción y devolver control mediante debrief y recuperación.
3. No confundir personalización con precisión psicológica.
4. No usar información sensible para aumentar impacto.
5. Explicar el mecanismo que produjo la experiencia.
6. Evaluar proceso, no solo acierto o resultado.
7. Normalizar el error y entrenar recuperación.
8. No prometer detección infalible.
9. Enseñar verificación independiente y acciones proporcionales.
10. Preservar privacidad, consentimiento y derecho a no participar.

## Prohibiciones

Las actividades no deben:

- solicitar ni recolectar credenciales, documentos de identidad, secretos empresariales o datos bancarios;
- usar identidades reales sin permiso;
- explotar duelos, emergencias, salud u otras vulnerabilidades sensibles;
- producir pérdidas reales o acciones irreversibles;
- exponer públicamente respuestas individuales;
- almacenar conversaciones privadas sin propósito, consentimiento y protección definidos;
- presentar una inferencia de IA como diagnóstico o verdad personal;
- utilizar vergüenza, ridiculización o miedo sostenido como mecanismo de aprendizaje.

## Diseño seguro de simulaciones

Las simulaciones deben ser reversibles, delimitadas y reconocibles como tales al cierre. Deben ofrecer consentimiento informado proporcional, rutas para no participar, protección de datos, feedback explicativo y un debrief que restituya agencia.

Mostrar patrones agregados o anónimos puede normalizar reacciones humanas sin señalar individuos. El error se trata como una oportunidad de observar el sistema y practicar recuperación.

## Responsabilidad distribuida

La ética aplica también a la organización: no puede exigir decisiones seguras dentro de procesos que castigan la pausa, impiden verificar o dejan a una persona sola frente a consecuencias sistémicas.
